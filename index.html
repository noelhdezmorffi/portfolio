Proyecto principal

RPG 2D Multijugador Online

Proyecto personal desarrollado con Unity y C#, enfocado en gameplay 2D, arquitectura de sistemas y networking multiplayer.

RPG 2D Multiplayer

Unity 6.3 · C# · Netcode · Unity Relay

RPG 2D multijugador online desarrollado como proyecto personal. El objetivo del proyecto es desarrollar de forma práctica diferentes sistemas de un videojuego y aprender cómo integrarlos dentro de una experiencia multijugador.

🎮 Gameplay

Movimiento en cuatro direcciones, colisiones y sistemas básicos del jugador.

🎨 Animaciones 2D

Animaciones mediante Blend Trees y sprites creados con Aseprite.

🌐 Multiplayer

Lobby, Unity Netcode for GameObjects y conexión mediante Unity Relay.

🗺️ Mundo 2D

Tilemaps, escenario, colisiones y ordenamiento visual mediante posición Y.

📷 Cámara

Cámara del juego implementada utilizando Cinemachine.

👤 Personajes

Sistema de selección de personajes dentro del entorno multijugador.
